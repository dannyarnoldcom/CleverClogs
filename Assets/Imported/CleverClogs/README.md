# Clever Clogs

Typed element access for Unity UI Toolkit. It knows all your UXML elements.

Clever Clogs scans a UXML file for named elements and generates a helper class with an enum of those names and a typed property for each element, then keeps the class up to date when the UXML changes.

Open it from `DADCTools > Clever Clogs`.

Full documentation: https://github.com/dannyarnoldcom/CleverClogs
