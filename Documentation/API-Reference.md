## Generate

**Namespace**: `DADC.Clogs`  
**File**: `Generate.cs`  
**Type**: `static class`

### Constants

#### Header

**Type**: `string`  
**Value**: `"// <auto-generated>"`

First line of every generated file. Used to recognise files that may be overwritten.

### Methods

#### BuildSource

Builds the source of a helper class holding an enum of the named elements in a UXML file and a typed property for each of them.

**Signature**:
```csharp
public static string BuildSource(string className, string uxmlPath, IList<Element> elements, string namespaceName, out List<string> warnings)
```

**Parameters**:
| Name | Type | Description |
|------|------|-------------|
| `className` | `string` | Helper class name; converted with `ToIdentifier` |
| `uxmlPath` | `string` | Asset path of the source UXML file |
| `elements` | `IList<Element>` | Elements to generate |
| `namespaceName` | `string` | Namespace for the class; null or empty for none |
| `warnings` | `out List<string>` | One message per renamed or skipped element |

**Returns**: `string` - The generated source. Nothing is written to disk.

**Exceptions**: None

---

#### WriteFile

Writes source to `folder/className.cs` and imports it.

**Signature**:
```csharp
public static string WriteFile(string folder, string className, string source)
```

**Parameters**:
| Name | Type | Description |
|------|------|-------------|
| `folder` | `string` | Project-relative output folder; created if missing |
| `className` | `string` | File name without extension; converted with `ToIdentifier` |
| `source` | `string` | Text to write |

**Returns**: `string` - Asset path of the written file

**Exceptions**:
- `ArgumentException` - `folder` is null or empty
- `IOException` - The file exists and was not generated by Clever Clogs

---

#### ToIdentifier

Turns any string into a PascalCase C# identifier.

**Signature**:
```csharp
public static string ToIdentifier(string name)
```

**Parameters**:
| Name | Type | Description |
|------|------|-------------|
| `name` | `string` | Any string; null is treated as empty |

**Returns**: `string` - A valid identifier, e.g. `"submit-button"` gives `"SubmitButton"`, `"2nd-item"` gives `"_2ndItem"`

**Exceptions**: None

---

### Generated Class

Members of a class produced by `BuildSource`, where `TElement` is the resolved type of each element:

| Member | Description |
|--------|-------------|
| `enum Element` | One value per generated element |
| `const string UxmlPath` | Asset path of the source UXML file |
| `static string NameOf(Element)` | The name the element has in the UXML file |
| `static T Q<T>(VisualElement root, Element)` | Queries any tree by enum value, without creating an instance |
| `(VisualElement root)` constructor | Queries every element once; throws `ArgumentNullException` if `root` is null |
| `VisualElement Root` | The root passed to the constructor |
| `TElement <Name>` | One read-only typed property per element; null if not found under `root` |
| `VisualElement Get(Element)` | The property matching the enum value |
| `T Get<T>(Element)` | As `Get`, cast to `T`; throws `InvalidCastException` on a type mismatch |

## Element

**Namespace**: `DADC.Clogs`  
**File**: `UXMLScan.cs`  
**Type**: `struct`

### Properties

#### name

Element's name from UXML.

#### type

Element's type (e.g., "Button", "Label").

**Type**: `string`  
**Access**: Public

#### elementType

The element's runtime type. `Generate.BuildSource` uses it to type the generated property.

**Type**: `System.Type`  
**Access**: Public  
**Default**: `null`, which generates a `VisualElement` property

#### selected

Indicates whether the element is selected for code generation.

**Type**: `bool`  
**Access**: Public  
**Default**: `false` (set in constructor)

**Usage**: The editor window sets this from the tick box in the element list and only generates selected elements. `Generate.BuildSource` itself ignores it and generates every element it is given.

---

### Constructor

Creates a new Element with specified name and type.

**Signature**:
```csharp
public Element(string name, string type, System.Type elementType = null)
```

**Parameters**:
| Name | Type | Description |
|------|------|-------------|
| `name` | `string` | Element name from UXML |
| `type` | `string` | Element type name for display (e.g., "Button", "Label") |
| `elementType` | `System.Type` | Element's runtime type; optional |

**Example**:
```csharp
var element = new Element("MyButton", "Button", typeof(Button));
// element.selected is false by default
element.selected = true; // Mark for code generation
```

## Compatibility

| Component | Unity Version | .NET | C# |
|-----------|--------------|------|-----|
| CleverClogsWindow | 2022.1+ | .NET Framework 4.7.1 | 9.0 |
| PathScan | 2021.3+ | .NET Framework 4.7.1 | 9.0 |
| UXMLScan | 2021.3+ | .NET Framework 4.7.1 | 9.0 |

| Generate | 2021.3+ | .NET Framework 4.7.1 | 9.0 |

**Note**: UI Toolkit support required. The editor window needs Unity 2022.1 or later because its element list uses `MultiColumnTreeView`. The tool compiles and its automated tests pass on Unity 2022.3 and 6000.5; the editor window has only been used on 6000.5. Generated classes use no language features beyond C# 6.

## Thread Safety

⚠️ **All APIs are NOT thread-safe and must be called from Unity's main thread.**

Unity Editor APIs (AssetDatabase, ScriptableObject, etc.) are not thread-safe and will throw exceptions if called from background threads.
